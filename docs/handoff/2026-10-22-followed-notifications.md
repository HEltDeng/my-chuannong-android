# 2026-10-22 正式端点与关注通知

正式 API 默认端点写入 `https://chuannong-api.mychangliapp.cn/api/v1/`，保留配置覆盖能力和端点安全校验。

“我的 → 通知设置”增加各板块关注开关。所有板块默认不关注；服务端保存成功后才更新开关，失败明确提示未保存。关注时可请求系统通知权限，仍可前往系统设置管理。

APP 启动/回前台只从鉴权的关注通知流生成通知与弹窗，不再根据公开 bootstrap 的公告标志提醒。投递状态按账号隔离，账号切换或退出时丢弃旧请求结果并清除弹窗；取消关注与拉取串行，成功取消后清除该板块已有本地通知。一次同步最多提醒最新一条，避免历史消息集中打扰。

Release Kotlin 编译及 363 项 JVM 测试通过（0 失败、0 跳过）。包含账号切换、退出和响应账号不匹配的通知阻止规则。后台配套 117 项测试通过。

尚未生成或安装新的 APK：用户要求等待高德企业认证完成后再获取 Key、按原 JKS 构建。未使用替代签名，也没有通过调试包替代交付。原 JKS 已存在仓库外。

关闭 APP 后接收系统通知仍待推送平台及厂商通道配置、真机验证。当前不包含已可用的远程推送 SDK，不把前台同步描述成离线推送。用户要求只向主动关注的用户发送，后续远程推送必须继续在服务端检查同一关注状态，并在退出账号时解绑设备。
