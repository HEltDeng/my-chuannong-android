# 首次绑定与本地数据保留

2026-10-18 最新用户要求取代此前“在线会话过期后撤销绑定许可”的规则。本轮聚焦清掉后台后重新启动弹绑定页的问题，跨学校服务的统一认证复用另行处理。

首次安装仍须同意条款并完成学校身份核验。核验成功后保存的加密绑定凭据代表完成首次绑定，独立于短期教务 Cookie。教务请求返回过期、会话文件丢失或服务端账号变化时，仅停止在线读取并清理失效会话，保留当前绑定身份与本地课表、成绩；不会切换到另一个学校账号的数据，也不会触发全局绑定页。

首页启动和回前台仅读取本机缓存。首次绑定内的数据获取继续保留，用户主动刷新可获取新数据。手动刷新首页/课表发现会话失效时显示可取消的登录提示；成绩页保留缓存并提供登录按钮。可选登录取消或失败不会撤销已有绑定，成功后返回发起页面。显式解绑仍立即撤销绑定凭据并清除学习缓存；从未完成绑定、凭据损坏或身份不匹配仍不能进入主功能。

回归覆盖：学校 HTTP 401 后保留绑定与缓存；错误学校账号不能覆盖本地数据；首页启动/回前台不发送教务请求；主动刷新才显示登录提示；取消登录继续看缓存；真实进程强制停止后冷启动；首次绑定与显式解绑边界。全部使用隔离包和合成账号/数据，不使用真实学校凭据。

升级限制：旧版本若已经把加密绑定凭据撤销并删除教务会话，无法仅凭普通本地标记安全恢复核验凭据，可能需要在新版本完成一次绑定。新版本不会因教务登录过期再次撤销它。请覆盖安装保留数据；卸载或清除应用数据会移除本机绑定与缓存。
