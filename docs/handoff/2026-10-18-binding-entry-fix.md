# 绑定成功与启动验证修复（2026-10-18）

本说明按用户后续截图反馈，替代同日 `2026-10-18-binding-onboarding.md` 中“每次冷启动/回前台联网复核”的行为；原绿色页面、键盘适配和首次强制绑定继续保留。

## 问题与变更

- 原绑定成功回调清除了刚验证成功的许可，并经入口页重复请求学校身份接口。重复请求遇到网络/VPN 故障时错误停留在重试页。现由认证流程保存成功凭据并恢复许可，绑定页直接打开首页。
- 原后台生命周期会撤销许可，冷启动也没有可恢复凭据。现取消后台撤销和启动网络关卡，入口只负责条款与首页/绑定页分流，不再绘制验证进度或重试页。
- 绑定凭据使用 Android Keystore AES-GCM 保存在 no-backup 目录，不包含密码；身份必须与当前学号一致。普通 MMKV 标记、返回或直接功能页 Intent 不能放行。
- 旧版成功登录保存的加密教务会话可以一次迁移。新版会话带版本标记；凭据损坏、删除或明确撤销后，不能凭旧标记/后到的 Cookie 刷新恢复许可。明确失效写入加密撤销记录，仅新的成功认证恢复。
- VPN 通道不可用及普通网络失败只影响在线读取，不把已绑定用户踢出应用。正常业务读取确认教务会话失效、账号不符或用户解绑时仍重新登录。

## 验证

使用隔离 `.bindingtest` 包和合成学校 HTTP 响应验证：成功绑定后进入首页不再额外请求本人资料接口，随后断网仍进入首页；前后台切换不撤销绑定；条款和首次绑定不可绕过；篡改加密凭据拒绝放行；旧会话迁移与撤销持久化；键盘与提交按钮回归。另做强制停止后的离线冷启动检查。最终测试结果记录于本次输出的验证说明。

结果：285 项 JVM 测试通过；14 项设备场景通过（完整运行中 13 项通过，另 1 项修正将首页正常后台请求误计为入口请求的断言后复测通过）；Debug/Release Lint 均 0 错误。隔离设备断网、强制停止后的冷启动最终 Activity 为 `MainActivity`，页面无验证/重新验证/首次介绍文案。静态检查保留已有警告，未扩展清理其他功能。
