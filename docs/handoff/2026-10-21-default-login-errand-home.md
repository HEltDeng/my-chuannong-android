# 默认登录保持、跑腿权限与首页卡片

## 本次确认

用户明确要求取消首次学校登录的保存勾选并默认启用恢复，覆盖此前手动勾选的规则。首页详细要求和验收条目相反，用户随后确认采用详细要求：仅移除成绩缓存说明，保留考试“查询成功，暂无数据”，把考试空数据卡片改成长条。

## 实现

- 绑定页移除保存账号密码的复选框和文字。NativeBindingViewModel 默认启用教务恢复；只有学校验证账号、密码和本人身份成功后才保存凭据。沿用 Android Keystore AES-GCM 加密和不可备份目录，优先官方会话，既有失败计数、冷却、验证码/短信/二次认证限制不变。
- 学校账号页仍能关闭自动登录并删除凭据；解绑或退出学校账号清除。重新手动登录教务后默认启用恢复。过去没有保存的密码不会被补录，需下一次本人成功登录才能保存。未采集川农 e 网页密码，其官方会话仍按现有机制保存和复用。隐私说明同步更新。
- 跑腿入口使用 AccountAccess；ErrandActivity 继承 AccountProtectedActivity，覆盖直接启动、任务恢复、回到前台和退出登录。登录/注册续接仍由 AccountRequiredActivity 完成；保存海报、打开微信及页面内容保持原样。
- HomeScoreSummaryCard 仅删除缓存说明行，四项成绩与眼睛折叠和成绩跳转保留。考试空数据卡片填满可用宽度，使用与课程卡片相同的 28 dp 圆角、20 dp 页面侧边距，保留消息和原“查看全部”入口。
- 不更改学校认证协议、后台接口或账号隔离；保留前序密码输入光标修复、首页无下拉刷新及课表按钮刷新行为。
