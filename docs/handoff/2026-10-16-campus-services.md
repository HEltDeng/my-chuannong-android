# 2026-10-16 雅思托福、考公考研与健身房接入

用户先验收三个独立交互原型，按截图删减并统一为「三个长条机构入口 → 机构详情」，随后明确要求全部加入 APP。本次将最新确认版本接入现有「服务 → 校外园地」，沿用驾校的本地资源方案。

## 已接入行为

- 雅思托福：青禾语言、远帆语学、知行语学。雅思 / 托福方向、班型筛选、课程详情、2–3 个套餐对比、师资与试听预约。
- 考公考研：知序研习社、青岸学堂、启程研习中心。考研 / 考公方向、套餐筛选与对比、学习服务及 30 分钟规划预约。
- 健身房：青岚运动馆、元气健身空间、星澜健身中心。设施介绍、泳池、月 / 季 / 年卡、健身与游泳权益、办卡意向、团课及场馆体验预约；元气无泳池，相关权益禁用。
- 三家机构各自使用独立价格和筛选状态，预约结果归属实际选择的机构，可继续查看、改期和取消。
- 三个入口都从机构列表开始，列表没有预约底栏。详情仅保留主预约按钮。已经删除的促销、问卷、常见问题和装饰内容不会重新出现在详情页。
- 原生标题栏保留 APP 的返回样式，隐藏网页重复标题及桌面预览外壳。系统返回与标题返回都遵循「弹窗 → 详情 → 列表 → 原 APP 页面」。页面不会在某个原生标题下跳到其他板块。

## 实现与维护

- `app/src/main/assets/campus-services/`：四个离线资源文件，为 APP 版本的维护源。SVG、样式和数据均本地提供，无外部字体或图片。
- `CampusServicesActivity.kt`：共用原生宿主，按受限枚举选择板块；非 exported Activity。使用 WebViewAssetLoader、关闭网络加载及文件 / content 访问，不提供 JavaScript 原生接口。
- `CampusServicesWebPolicy.kt`：仅允许四个资源的精确 HTTPS 地址；拒绝跨资源目录、路径编码变体、外部 URL 和其他协议。
- `FunctionCatalog.kt`：保留三项稳定 ID、排序和可见性控制，从 ComingSoon 改为各自本地目标，旧配置缺少条目时仍补齐；配置中的 URL 不能覆盖这些本地入口。
- `window.CampusServices.back()`：仅供原生宿主执行返回，由网页判断关闭弹窗或返回列表，列表返回 false 让 Activity 退出。
- `tools/export_campus_services_preview.cjs`：从 Android 资源导出四个独立 HTML。运行 `node tools/export_campus_services_preview.cjs <绝对输出目录>`。

原型原始交付保留在工作区 `05_Output/campus-services-prototypes-20261016/`，本次 APK、日志、模拟器截图和校验清单保存在 `05_Output/campus-services-integrated-20261016/`。未来维护以 Android 仓库资源为准，不依赖工作区历史输出文件。

## 状态边界

商家、师资、地址、设施、价格、余位和服务规则仍为虚构示例。预约日期固定为 2026 年 10 月 17–20 日。提交前和结果中保留模拟说明，不收集个人联系方式、不付款、不发送真实预约。数据仅保留在当前页面内存中，退出、重建或刷新后清空。真实运营需要另接商家资料、预约库存及账户服务。

没有修改后台、学校认证、课表、已有驾校和二手模块；保留工作区其他未提交改动。交付为本地内部 Debug 包，没有正式发布、推送或生产部署。

## 验证入口

- JVM：`FunctionCatalogTest` 检查默认及旧配置的实际路由；`CampusServicesWebPolicyTest` 检查模块与离线资源边界。
- 设备：`CampusServicesIntegrationDeviceTest` 检查九家机构、原生视口、逐级返回、课程与会员交互、模拟预约、改期取消及页面截图；`CampusServicesEntryDeviceTest` 点击实际校外园地组件，确认三个入口对应模块且可返回。
- 设备测试使用 `.campusservicestest` 隔离包。最终交付恢复默认 Debug 包名，不覆盖原有应用数据。设备为 Android 模拟器，尚未验证多品牌真机。
