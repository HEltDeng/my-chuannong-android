# 校园地图交互升级 · 2026-10-17

## 本次范围

按用户上传的 48 秒视频参考全屏地图、浮层列表和连续镜头移动。用户确认本轮先完成离线立体示意地图；不接入高德在线底图。本轮从现有 Android 源码继续，学校服务入口及其他业务逻辑保持原状。

## 已实现

- 原生全屏地图，以独立的 Canvas 视图绘制可倾斜、旋转的建筑模型、园区和道路示意。单指拖动、双指缩放/旋转、双指上下滑动调整倾角，双击放大；提供查看全校、俯视/立体、旋转、加减按钮。
- 原生 Material 3 底部面板，拖动展开/收起，列表嵌套滚动；搜索获取焦点时展开，键盘通过窗口 Insets 适配。
- 八类地点：全部、教学楼、宿舍、食堂、图书馆、体育场馆、生活服务、校门。目录未录入某类时不展示空分类。
- 分类同步更新列表与地图，非匹配建筑保留低对比轮廓作方位参照。选中建筑使用绿色屋顶、白色描边、地面轮廓和名称标签；对应列表项同步高亮并滚动到可见位置。
- 点列表或地图建筑均触发 680 ms 连续镜头移动，保持现有旋转方向，缩放到合适范围。新目标从当前动画帧继续，不从上个起点重新播放。建筑投影中心随面板位置变化，选中后收起面板，建筑位于面板上方。
- 搜索覆盖三个校区全部已收录地点，不受分类限制。支持名称、阿拉伯/中文楼号、简称、关键词、多词组合、全角数字；数字边界避免“1号”误匹配“11号”。空结果与一键清空均已实现。
- 选择搜索结果时关闭键盘、清空查询、同步校区/分类/列表和地图。保存校区、分类、选中地点、查询与镜头，重建后恢复。
- 顶部“原图”保留原始手绘地图和双指缩放；图片资源未修改。主地图、原图和地点搜索都无需网络或登录。

## 高德评估与后续接口

高德 Android 3D SDK 支持旋转/倾斜、相机动画和自定义建筑，但接入需要本产品的有效 Android Key（包名和签名匹配）、对应 SDK 的隐私流程，以及核实过的 GCJ-02 坐标/建筑轮廓。项目当前没有这些配置，且用户明确选择先交付离线示意图。

官方依据：
- https://developer.amap.com/api/android-sdk/guide/create-project/dev-attention
- https://developer.amap.com/api/android-sdk/changelog/3d
- https://a.amap.com/lbs/static/unzip/Android_Map_Doc/3D/com/amap/api/maps/AMap.html

地点 ID、校区、分类、别名与 UI 状态独立于绘图层，后续可替换地图渲染器，但不能把本轮插画坐标直接当作经纬度使用。
