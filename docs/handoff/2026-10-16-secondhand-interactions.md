# 二手好物筛选、发布与联系方式 · 2026-10-16

## 当前行为

最新决定：取消站内聊天，改为展示发布人主动填写的微信号、联系电话，由查看者自行联系。

- 移除“聊一聊”入口、聊天页面、输入栏、消息收发 API、消息草稿、相关样式及专用图标。旧会话链接进入首页，不创建会话。
- 出售和求购均提供“微信号”“联系电话”，至少填写一项；填写的项目随发布内容保存，空项目不显示。微信号优先展示，电话可单独使用。表单明确说明这些信息会随发布内容展示。
- 列表不直接展示微信号或电话；点击出售卡片、求购内容或“查看联系方式”进入详情，出售与求购详情均展示联系方式，提供“复制微信”“复制电话”。复制成功后才提示成功；不支持自动复制时保留长按复制文字的方式。
- 根据用户后续要求，首次打开或升级时补充 6 条出售、3 条求购示例，覆盖雅安、成都、都江堰。固定 ID 和 sampleRevision 保证重开不重复添加，保留已发布内容与校区偏好。示例联系人采用占位值。没有匹配结果时仍显示“暂无相关信息”；旧商品若未留联系方式，显示“发布人暂未留联系方式”。
- 保留绿色配色、出售双列布局、圆形加号、出售/求购切换、自定义分类和校区底部面板。列表和详情不包含价格或预算字段。
- 校区包括雅安、成都、都江堰和全部，切换出售/求购保留校区与关键词。标题、描述、分类、校区均参与关键词匹配，搜索与校区、分类条件同时生效。
- 出售最多选择四张图片，支持预览、移除和重新打开后显示；求购不要求图片。两种发布类型分别保留未提交草稿，包括联系方式；选择分类、校区时继续保留草稿。

## 源码入口

- `app/src/main/assets/secondhand/app.js`：路由、发布、图片处理、选择面板、联系方式展示和复制。
- `app/src/main/assets/secondhand/store.js`：搜索规则、联系方式验证、数据白名单、结构升级、示例合并和串行写入。
- `app/src/main/assets/secondhand/samples.js`：用户要求的出售、求购示例和插画名称，不包含真实联系人或价格。
- `app/src/main/assets/secondhand/styles.css`：绿色页面、双列卡片、选择面板与联系方式布局。
- `app/src/main/java/com/mychuannong/app/feature/common/ui/SecondhandActivity.kt`：原生容器、图片选择、表单键盘边距和返回处理。
- `tools/test_secondhand.cjs`：数据层回归。
- `app/src/androidTest/java/com/mychuannong/app/feature/common/ui/SecondhandIntegrationDeviceTest.kt`：设备端筛选、搜索、发布、复制、旧数据升级及图片选择回归。

## 本地状态与升级

IndexedDB 数据库仍为 `mychuannong-secondhand`，数据库版本 1、对象仓库 `content`、键 `state`。状态内容版本为 2，保存商品/求购、图片、插画名称、联系方式、筛选偏好与 sampleRevision。示例内容只在 revision 首次引入时合并，已存在的 ID 不覆盖；初始化写入失败时保留原状态并提供重试。读取旧版状态时保留原有发布内容、图片和偏好，补充空联系方式并移除旧会话数据；升级写入成功后才开放页面。无法读取或保存时提供重试反馈，不假报成功或静默覆盖损坏数据。

联系方式是纯文本，不执行 HTML，不自动打开微信、拨号或向第三方发送内容。复制使用 Clipboard API，并为 Android WebView 提供选区复制兼容处理，无新增原生 JavaScript 桥。

仍未接入跨设备内容服务；新设备默认没有其他设备发布的信息。没有新增支付、交易、学校身份访问或网络请求。图片仅接受用户主动选择的内容授权，保留 WebView 导航来源限制、禁止网络加载和禁止混合内容的设置。图标许可继续随资源提供。

## 我的发布

“求购”和校区筛选之间新增“我的”，进入后按全部、出售、求购查看本机当前身份发布的记录，不受首页的搜索或校区条件限制。示例发布人和其他 ownerId 不显示在这里，也不能通过数据层更新或删除。

编辑复用发布表单，支持图片、标题、描述、分类、校区与联系方式，保留记录 ID、归属、类型与原发布时间；保存成功后回到管理列表，同时更新普通出售/求购列表。编辑草稿与新发布草稿分开。求购仍不提供图片、价格或预算。

删除使用自定义圆角确认面板，取消不修改记录；确认并成功写入后才移除。保存、删除失败保留原记录并提供重试。重开页面后编辑结果和删除结果保留，sampleRevision 不会恢复自己删除的发布。

本轮 25 项数据检查、6 项 Android 设备检查通过，包括编辑时保留图片和联系方式、两种发布类型、取消删除与确认删除、重开、归属限制和写入失败。证据目录：`05_Output/secondhand-mine-20261016/`。更新默认 Debug 包并覆盖安装到用户使用的模拟器应用，保留原数据。
