## 构建与协议来源

`app/build.gradle.kts` 默认从仓库外 `~/.local/share/my-chuannong/legal/2026-11-17.1/` 读取 `MyChuannongLegal.json`，可用 `-PmyChuannongLegalDir=...` 指定。构建校验版本和四份正文完整性，仅复制该 JSON 到生成的 assets，不打包相邻原始文件。原始协议、签名及私密配置不进入 Git。

从开发根目录加载 `scripts/env.sh` 后运行：

```sh
cd my-chuannong-android
./gradlew :app:testReleaseUnitTest :app:assembleRelease :app:lintVitalRelease --no-configuration-cache --console=plain
```

完整历史交付工具 `tools/build_release.py` 仍要求干净提交；本次工作树含此前修改，直接以 Gradle 构建本地验收包，单独记录源码树状态，不将其冒充某个干净提交的发布包。
