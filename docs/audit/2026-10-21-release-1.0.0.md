## 剩余限制

1. **签名与服务**：原密钥需在用户 Mac 本机解密并核对，才能构建可覆盖原签名安装的包；账号 HTTPS 后台和原签名对应高德 Key 尚未配置。保留用户已授权的“服务未部署、本地审核”构建选项，不假装服务可用。
2. **既有 HTTP 电费入口**：`bd.bdfairy.cn` 的精确主机 HTTP 兼容例外仍存在；需服务提供方给出可用的 HTTPS 入口才能替换。未为了审计修改冻结功能。
3. **构建供应链**：wrapper 校验和、版本固定、npm integrity 与源码校验已存在；Gradle 仍缺完整逐制品校验元数据，Python lock 尚无逐制品 hash。干净副本能构建不等于可以保证所有机器生成逐字节相同 APK。
4. **技术债**：1507 条 Lint 警告和大型后台模块尚待分批处理。没有为了“清零”删除可能由动态加载使用的资源或重构冻结界面。
5. **再分发与在线验收**：保留现有许可声明，完整素材授权清单尚待公开分发前核对。未进行公网部署、真实学校二次认证、跨厂商保活或新的正式签名包设备验收。

本报告是自动扫描配合关键代码路径审查，不是全量形式化证明或第三方渗透测试。旧 2026-10-13 报告的后台缺失模块/失败测试与更新下载边界已在当前版本解决；上述 HTTP、制品校验、技术债与许可事项仍保留。
